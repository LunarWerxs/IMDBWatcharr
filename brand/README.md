# Watcharr logo

Vector files, generated from geometry by the logo repo's `tools/marks_watcharr.py --site` (do not edit by hand).

| File | Use it for |
| --- | --- |
| `watcharr.svg` | The logo with the name, on a light background |
| `watcharr_white.svg` | The logo with the name, on a dark background |
| `watcharr_mark.svg` | The bookmark alone, on light |
| `watcharr_mark_white.svg` | The bookmark alone, on dark |
| `watcharr_mark_mono.svg` | The bookmark in one colour (charcoal) |
| `watcharr_icon.svg` | The favicon: turns its charcoal white in a dark browser |
| `watcharr_tile.svg` | The bookmark on a light rounded square, for app and catalog tiles |

Colours: gold `#F5C518`, charcoal `#2B3138`. The name is Poppins Bold (SIL Open Font License), baked into the files as outlines.
