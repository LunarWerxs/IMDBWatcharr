How it works ›

1

Paste a public IMDb link

Open your watchlist (imdb.com/user/ur.../watchlist/) or a list (imdb.com/list/ls...) and copy the address. Make sure it is public.

2

Copy your two links

The same list always gives you the same two links, so you set this up once.

3

Paste them into Radarr and Sonarr

Radarr takes the movies link as an RSS list. Sonarr takes the shows link as a custom list.
